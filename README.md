# Christ Tech landing page replica

A responsive HTML/CSS recreation inspired by the supplied screenshot.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Internet access is needed for Google Fonts and the remote photo URLs.

## Files
- `index.html` — page structure and content
- `style.css` — layout, colors, spacing, typography, and responsive rules

Note: The supplied screenshot is a visual reference. The images currently use remote Unsplash photos as placeholders, so the result approximates the screenshot rather than reproducing its exact original image assets.
